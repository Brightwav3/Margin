# Handoff — stav projektu k 2026-09-29 (ráno po nočním cloudovém běhu)

Určeno pro **lokální session** (Claude Code na Macu s Xcode 27), která navazuje na dlouhou konverzaci. Přečti nejdřív `AGENTS.md` a `docs/plan/STATUS.md`, potom tento soubor.

## 1. Co je Margin (jednou větou)
macOS aplikace (Swift 6.4, SwiftUI + AppKit, jen Apple Silicon) na studijní poznámky a úkoly pro vysokoškoláky: markdown jako Obsidian, úkoly jako Things 3, vše kolem semestru; navržená i pro použití AI agenty. Zdroj vzhledu: mockupy z Claude Design v `docs/design/mockups/` (čti HTML přímo).

## 2. Rozhodnutí z konverzace (plné znění: `docs/plan/DECISIONS.md`, D-001…D-016)
- **Stack:** Swift + SwiftUI + AppKit (editor `NSTextView`/TextKit 2), jen arm64, deployment target aktuální SDK (macOS 27), žádné třetí strany.
- **Data:** vault = složka markdown souborů (kompatibilní s Obsidianem), index jen cache. Stabilní ID (`id:` v poznámkách, `^t-…` u úkolů). Formát: `docs/plan/05-vault-spec.md`.
- **Ikony:** Lucide (jako Obsidian), generované jako Swift `Shape` z pinované verze SVG.
- **Plán:** 21 milestonů, rozdělených na **backend (`core`)** a **UI (`ui`)**, spojených smlouvou `Sources/MarginCore/API` (`docs/plan/09-contracts.md`). Úkoly mají ID (např. `M5-06`, `AG-03`) a **váhu** (ne čas): `docs/plan/backend/README.md`, `docs/plan/ui/README.md`. Hodinové odhady byly záměrně zrušeny (D-014), práci dělají agenti.
- **Agenti jako uživatelé (D-011, D-013):** klient (CLI/MCP/HTTP) × identita (role s oprávněními), review fronta, audit, undo. Plán: `docs/plan/10-agent-native.md`. **Agentní vrstva je zatím odložená** (AG-01, AG-05…AG-36); zůstaly jen AG-02, AG-03, AG-04.
- **Git workflow (D-016):** GitHub + Conventional Commits + PR, větve `<type>/<scope>-<slug>`, patička `Task: M3-05`, squash merge; hooky a guard vynucují pravidla (`docs/git-workflow.md`, `AGENTS.md`). Ruleset na `main` **není k dispozici** (soukromé repo na free plánu, R-21).
