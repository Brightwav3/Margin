# Referenční snímky mockupů

PNG vykreslené z mockupů Claude Design (`docs/design/mockups/*.dc.html`) přes WebKit, jeden soubor na mockup
(celé plátno). Slouží k porovnání se snímky aplikace v `../snapshots/` (`scripts/snap.sh <id>`).

Přegenerování (potřebuje síť kvůli písmům z Google Fonts):

```bash
scripts/ref-mockups.sh
```
